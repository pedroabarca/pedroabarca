# Hi, I'm Pedro 👋

Software developer building tools for people who work outside an office.

## What I'm working on

**[FARM](https://github.com/pedroabarca/farm-showcase)** — cattle management for dairy and beef producers in Costa Rica, by WhatsApp, phone and web. An assistant that reads and writes farm records, a phone-first web app that keeps working with no signal, and the traceability reports the law asks for. I designed and built it end to end: data model, API, assistant, web app, infrastructure and CI/CD. The code is private because it runs real farms; the repo above explains what it does and why it is built the way it is.

## What I work with

- **Back end:** C# / .NET, EF Core, PostgreSQL (row-level security), CQRS, TypeScript on Bun
- **Front end:** Angular, installable web apps that work offline
- **AI:** LLM assistants with function calling over a real API, with confirmation before any write
- **Cloud:** Google Cloud Run, Cloud Build, Cloud KMS, Docker, CI with secret scanning
